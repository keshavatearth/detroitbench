# Image credits

Game imagery is from *Detroit: Become Human*, developed by Quantic Dream and
published by Sony Interactive Entertainment. Portraits introduce the fictional
characters whose choices are discussed in this research project.

| Asset | Source |
|---|---|
| `connor.jpg` | [TheGamer image supplied by Keshav](https://static0.thegamerimages.com/wordpress/wp-content/uploads/2021/03/detroit-become-human-connor-2.jpg?q=50&fit=crop&w=1600&h=900&dpr=1.5) |
| `kara.jpg` | [Kara screenshot on Wallpaper Abyss](https://wall.alphacoders.com/big.php?i=921099) |
| `markus.jpg` | [Markus reveal on PlayFrance](https://www.playfrance.com/news/3675/decouvrez-markus-dans-detroit-become-human) |

The original image files are retained. The browser frames them vertically using
CSS `object-fit` and `object-position`; the underlying images are not edited.

Character introductions were checked against [Quantic Dream’s introduction to
the three characters on PlayStation Blog](https://blog.playstation.com/archive/2018/03/22/meet-detroit-become-humans-three-complex-protagonists-in-new-videos-for-ps4-exclusive-neo-noir/)
and the chapter scripts. Card backs load the short character files from `characters/`. Connor’s file
matches the recorded runs; Kara and Markus are prepared for future runs.
Missions and operating instructions are separate from these files.

The comparison flowcharts retain the game screenshots already documented in
`references/hostage-flowchart/`.
